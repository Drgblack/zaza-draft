# UX Improvement - Zara Back Button

## Issue
Back arrow in header was too subtle. Even users who knew it existed struggled to find it.

## Solution
Added prominent "Back to Menu" button at bottom of content areas:
- Full-width purple button
- Clear text label
- Icon + text for clarity
- Appears after all content (natural reading flow)
- Still keeps header arrow for redundancy

## Why It Matters
If it takes the developer 30 seconds to find the back button, 
it will take teachers 2+ minutes or they'll give up entirely.

Good UX = Obvious navigation, no hunting required.
