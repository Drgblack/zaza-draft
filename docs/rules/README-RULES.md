## 🎯 RULE SYSTEM OVERVIEW

### Core Pillars

**1. Hallucination-Safe**  
Never invent facts about students. Only use teacher-provided information.

**2. Multi-Lingual Safety**  
Banned words detected across 9 languages to serve global classrooms.

**3. Cultural Neutrality**  
No religion, politics, or controversial topics. Safe for 100+ countries.

**4. Growth-Minded**  
Always encouraging, solution-focused, partnership-oriented.

**5. Pedagogically Sound**  
Evidence-based teaching practices aligned with K-12 education standards.

## ✅ QUALITY GATES

Every output must pass ALL checks:

```
✅ Word count: 95-120
✅ Exactly 3 paragraphs  
✅ ≥2 concrete action verbs present
✅ NO banned words (all 9 languages checked)
✅ No "delighted" in concern scenarios
✅ Pronoun agreement correct (via name database)
✅ Readability ~Grade 6-8 (Flesch-Kincaid)
✅ At least one strength/growth line included
✅ No invented facts or details
✅ Strategies from approved bank only
✅ Partnership language in closing
```

**If ANY check fails → Regenerate immediately**
