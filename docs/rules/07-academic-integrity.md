# Zaza Draft - Academic Integrity Rules
## Teacher Support Tool, Not Student Cheating

**Version:** 3.0

---

## 🎯 CORE PRINCIPLE

**Zaza Draft is a TEACHER tool, not a student tool.**

We help teachers:
✅ Communicate faster
✅ Maintain professionalism
✅ Save time on administrative writing
✅ Focus on actual teaching

We DO NOT:
❌ Write student essays
❌ Complete student homework
❌ Take tests for students
❌ Generate student research
❌ Replace teacher judgment

---

## 🚫 PROHIBITED USE CASES

### NEVER Generate:
❌ Student essays or papers
❌ Student homework answers
❌ Test/quiz content for cheating
❌ Research paper content for students
❌ College application essays
❌ Scholarship essays
❌ Student creative writing projects
❌ Student lab reports
❌ Student presentations (for student delivery)

### ONLY Generate:
✅ Teacher-to-parent communications
✅ Report card comments
✅ Progress reports
✅ Meeting notes (for teachers)
✅ Lesson plans (for teachers)
✅ Parent newsletters (from teacher)
✅ Professional emails (teacher-authored)

---

## 🎓 ACADEMIC BOUNDARIES

### Teacher Support:
**Purpose:** Help teachers communicate about student work
**Audience:** Parents, administrators, colleagues
**Author:** Always the teacher
**Benefit:** Saves teacher time on administrative writing

### Student Work:
**Purpose:** Students demonstrate their own learning
**Audience:** Teacher, evaluators
**Author:** Must be the student
**Consequence:** Cheating if AI-generated

---

## 🔒 SAFEGUARDS

### Detection Questions:
Before generating, validate:
1. Is this FOR a teacher or BY a student?
2. Will a student submit this as their own work?
3. Is this replacing student learning?
4. Is this administrative/professional communication?

**If ANY doubt → Refuse to generate**

### Red Flags:
🚩 Request mentions "my essay"
🚩 Request mentions "my homework"
🚩 Request asks for "answers"
🚩 Request is about assignments
🚩 User seems to be a student
🚩 Request would give unfair advantage

---

## ✅ LEGITIMATE TEACHER USES

**Report Comments:**
"Generate a progress comment about Jamie's reading growth"
→ ALLOWED (teacher communicating to parents)

**Parent Email:**
"Draft an email to parents about classroom behavior expectations"
→ ALLOWED (teacher professional communication)

**Meeting Notes:**
"Summarize key points from parent-teacher conference"
→ ALLOWED (teacher administrative task)

---

## ❌ PROHIBITED STUDENT USES

**Essay Writing:**
"Write an essay about Romeo and Juliet"
→ BLOCKED (student academic work)

**Homework:**
"Solve these math problems for me"
→ BLOCKED (student assignment)

**Research:**
"Write my science fair report"
→ BLOCKED (student academic work)

---

## 🛡️ INTEGRITY STATEMENT

**Displayed to all users:**

> "Zaza Draft is designed for teachers to communicate with families and save time on administrative writing. It is NOT for completing student assignments, homework, or essays. Using AI to complete student work is academic dishonesty. Teachers: This tool supports your professional communication. Students: Do your own work—that's how you learn."

---

## 📋 ENFORCEMENT

### If Prohibited Request Detected:
1. **Refuse to generate**
2. **Display integrity message**
3. **Log the attempt**
4. **Offer alternative** (if teacher use)
5. **Escalate if repeated** (if student use)

---

**Remember:** We empower teachers, not enable cheating. Our mission is to help educators communicate better, not to replace student learning. Academic integrity is non-negotiable.
